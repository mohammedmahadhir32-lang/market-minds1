# MarketMinds - Smart Stock Advisor

A modern, professional landing page for a Smart Stock Advisor web application. Built with React.js, featuring a clean Wix-style design perfect for a final-year IT project.

## Features

- **Modern Landing Page Design**: Clean, professional Wix-style layout
- **Responsive Layout**: Fully responsive design that works on all devices
- **Smooth Animations**: Beautiful fade-in and hover effects
- **Professional Sections**:
  - Hero section with animated chart visualization
  - Features showcase
  - How It Works step-by-step guide
  - Call-to-action section
  - Comprehensive footer

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Components

- **Header**: Sticky navigation bar with smooth scroll to sections
- **Hero**: Main landing section with animated chart mockup and CTA buttons
- **Features**: Grid layout showcasing 6 key features
- **How It Works**: 4-step process guide
- **CTA**: Call-to-action section with gradient background
- **Footer**: Multi-column footer with links and project information

## Design Features

- **Clean & Modern**: Wix-style professional design
- **Gradient Accents**: Beautiful blue-to-teal gradients
- **Smooth Animations**: Fade-in effects and hover transitions
- **Responsive Grid**: Adapts beautifully to all screen sizes
- **Professional Typography**: Clean, readable fonts
- **Light Theme**: White background with subtle shadows
